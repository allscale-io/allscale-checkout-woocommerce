# `.wordpress-org/` — WordPress.org plugin directory assets

These files become the visual identity of the plugin on its WordPress.org listing page (banner / icon) and the screenshots referenced from `readme.txt`'s `== Screenshots ==` section. They live **outside** the plugin code — when this plugin is approved for the directory, these assets get committed to a separate path in the SVN repo (`assets/`), not bundled into the plugin ZIP that merchants install.

The folder name `.wordpress-org/` is the convention recognised by [`10up/action-wordpress-plugin-deploy`](https://github.com/10up/action-wordpress-plugin-deploy) — a GitHub Action that mirrors this folder to the WP.org SVN `assets/` directory automatically when we tag a release. We don't run that action yet; it's set up for when the plugin clears WP.org review.

## Banner — placeholder status

The current `banner-*.png` files are **programmatically rendered placeholders** generated from `assets/icon.png` + a simple PIL composition (brand mark on the left, "Allscale Checkout" + tagline on the right, on the `--brand-l` background). They're legible and on-brand but were not put through a real design pass. Replace before submitting to WordPress.org.

When the real banners arrive (from Claude Design or a designer), drop them in at the same filenames — the rest of the pipeline will pick them up.

## Icon — re-render notes

`icon-128x128.png` and `icon-256x256.png` are square-cropped versions of `assets/icon.png` (the native asset is 512×397, non-square, because the corner brackets create a wider-than-tall composition). The square versions add ~12% transparent padding around the mark so it doesn't crowd the WP.org card edges.

If `assets/icon.png` changes, re-run the regeneration script — see the snippet at the bottom of this file.

## Regeneration script

The icons + placeholder banners are generated by a small Python script that lives in the commit history. To rebuild:

```bash
python3 <<'PY'
from PIL import Image, ImageDraw, ImageFont
import os

mark = Image.open("assets/icon.png").convert("RGBA")
mw, mh = mark.size

# Square-padded icons
side = max(mw, mh)
canvas = Image.new("RGBA", (side, side), (255, 255, 255, 0))
canvas.paste(mark, ((side - mw) // 2, (side - mh) // 2))
pad = int(side * 0.12)
inner = Image.new("RGBA", (side + 2*pad, side + 2*pad), (255, 255, 255, 0))
inner.paste(canvas, (pad, pad))
for size in (128, 256):
    inner.resize((size, size), Image.LANCZOS).save(
        f".wordpress-org/icon-{size}x{size}.png", "PNG", optimize=True
    )

# Banners (placeholder)
font_path = "/usr/share/fonts/truetype/dejavu/DejaVuSans-Bold.ttf"
for bw, bh in ((772, 250), (1544, 500)):
    c = Image.new("RGBA", (bw, bh), (230, 246, 244, 255))
    th = int(bh * 0.5); tw = int(th * (mw / mh))
    m = mark.resize((tw, th), Image.LANCZOS)
    mx = int(bh * 0.16); my = (bh - th) // 2
    c.paste(m, (mx, my), m)
    d = ImageDraw.Draw(c)
    ft = ImageFont.truetype(font_path, int(bh * 0.135))
    fs = ImageFont.truetype(font_path, int(bh * 0.07))
    tx = mx + tw + int(bh * 0.16)
    tbox = d.textbbox((0, 0), "Allscale Checkout", font=ft)
    sbox = d.textbbox((0, 0), "Crypto payments for WordPress", font=fs)
    tH = tbox[3] - tbox[1]; sH = sbox[3] - sbox[1]
    gap = int(bh * 0.025); ty = (bh - (tH + gap + sH)) // 2
    d.text((tx, ty), "Allscale Checkout", font=ft, fill=(29, 35, 39, 255))
    d.text((tx, ty + tH + gap), "Crypto payments for WordPress", font=fs, fill=(80, 87, 94, 255))
    c.save(f".wordpress-org/banner-{bw}x{bh}.png", "PNG", optimize=True)
PY
```
